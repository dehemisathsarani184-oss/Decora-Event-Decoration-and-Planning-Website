# Decora – Event Decoration & Planning Website

**Decora** is a full event decoration and planning website developed as a group project. It is designed for an event decoration business that creates memorable experiences for weddings, engagements, proposals, parties, and other special occasions.

The website provides an elegant and user-friendly platform where clients can explore event decoration services, compare packages, and submit booking requests.

## ✨ Features

- 🏠 **Home Page** – A welcoming landing page with an animated image carousel showcasing event decorations.
- 🏛️ **About Page** – Introduces the company, including its story, vision, and mission.
- 💐 **Services Page** – Displays different event decoration services with images and descriptions.
- 📦 **Decoration Packages** – Bronze, Silver, and Gold packages with features and pricing in Sri Lankan Rupees (LKR).
- 📝 **Booking System** – Allows clients to select an event type and package and submit their booking details.
- 🗄️ **Database Integration** – Stores booking information in a MySQL database.
- 📱 **Responsive Design** – Provides a mobile-friendly layout with a responsive navigation menu.
- 🔒 **Secure Form Handling** – Uses PHP prepared statements to handle database operations more safely.
